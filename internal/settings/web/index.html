Clipboard Translator

Settings

Quick start

    Hotkeys

    Select text in any program and press a hotkey. The translation replaces what is on the clipboard. Each hotkey can translate in its own way.

    Translation model

    Bigger models need more disk space, memory and time. A model is downloaded from Hugging Face only when you click Download, and it is checked against a fixed SHA-256 before it can be used. Switching reloads the model, which takes a moment.

    Built with PLaMo. The models are used under the PLaMo Community License; business use, including internal use, needs prior registration with PFN.

    Translation engine

    General

    Types the paste shortcut for you, but only when the text was a fresh selection and the same window is still in front.

    Shows a tray notification when the translation is ready in the clipboard.

    characters

    Longer selections are skipped instead of translated.

    minutes (0 = never)

    Frees RAM/VRAM while idle. The next translation loads the model again and takes longer.

    ChromeOS / local translation endpoint

    Off by default. Listens on all IPv4 interfaces, port 18121, for Crostini forwarding. Only clients with the token can translate; keep the token private. No external translation service is used.

    This page is served by the app on this computer only, and goes away when you close it. The hotkeys, auto-paste, notifications, longest text and idle unload time are saved with the Save button; choosing a model or engine takes effect at once. Other settings are in config.json (tray menu: Open config.json).
