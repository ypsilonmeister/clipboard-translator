Clipboard Translator

Settings

Hotkeys

Select text in any program and press a hotkey. The translation replaces what is on the clipboard. Each hotkey can translate in its own way.

General

Types the paste shortcut for you, but only when the text was a fresh selection and the same window is still in front.

This page is served by the app on this computer only, and goes away when you close it. Other settings are in config.json (tray menu: Open config.json).
